Interactive Excel Sales Dashboard using Pivot Tables, Pivot Charts and Slicers to analyze sales, transactions, customer segments and regional performance.
This project is an interactive Excel Sales Dashboard created using a Super Store sales dataset.
The dashboard provides business insights related to:

Total Sales
Average Sales
Total Transactions
Quantity Ordered
Regional Performance
Monthly Quantity Trends
Ship Mode Analysis
Category-wise Transactions
Customer Segment Analysis
Top 5 Cities by Sales
